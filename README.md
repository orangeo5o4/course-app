# 国科大选课助手（course-app）

面向国科大学生的模拟选课与课表管理工具。纯前端实现、零后端依赖，所有数据保存在本机，支持完全离线使用。

- 在线使用：<https://orangeo5o4.github.io/course-app/>
- 项目仓库：<https://github.com/orangeo5o4/course-app>
- 适用学期：2026 秋季学期（第 1 周从 2026-08-31 开始）

---

## 一、功能说明

### 1. 选课

- **课程搜索**：支持按课程名称、教师姓名、课程编号模糊搜索；多时段课程在搜索结果中完整列出所有上课时间
- **一键选课 / 一键旁听**：选课后自动分配颜色；旁听不占用选课名额
- **冲突检测**：与已选课程时间、周次冲突时弹出三种处理方式——放弃添加、仍然选择（标红提示）、转为旁听
- **旁听显示**：旁听课程在课表中以灰蓝斜纹块呈现，与已选课程冲突的时段自动隐藏

### 2. 课表展示

- **周视图**：周一至周日 × 13 节完整网格，连堂课自动合并为一个大块（如第 1-3 节）
- **自动教学周**：以 2026-08-31（周一）为第 1 周，打开自动定位当前教学周并高亮"本周"，也可手动切换 1-20 周
- **作息时间**：13 节（08:30 - 21:50），左侧时间列显示每节起始时间
- **长课名适配**：课程名自动换行，超出卡片高度时可在卡片内上下滑动，完整查看课程名、教师与教室
- **三类色块一眼区分**：课程 = 实心彩色块；旁听 = 灰蓝斜纹块；个人行程 = 浅底描边块

### 3. 今日页面

- 时间线形式展示今天的全部课程与个人行程
- 课程显示节次与上课时间段；个人行程显示真实钟点时间（如 12:10-13:20）
- 旁听与个人行程带标签标注

### 4. 个人行程

- **两种时间方式任选**：
  - 按课时：选第几节到第几节（选项附带时间提示，如"第 1 节 08:30"）
  - 按时间：直接选开始、结束钟点（06:00-23:00），如午休 12:10-13:20 也能创建
- 按钟表时间创建的行程会自动映射到课表网格，在周视图上有合理位置
- 8 种可选颜色，均与课程配色区分；支持备注

### 5. 数据导出

- **Excel 选课表**：一键导出 .xlsx，仅包含已选课程（不含旁听），含课程完整信息与上课时间
- **单周课表壁纸**：导出 PNG，适配手机屏幕比例，可直接设为手机壁纸
- **全学期长图**：导出 1-20 周课表长图（2 列 × 10 行 PNG）
- 导出图片中长课名自动换行、字号自适应，完整显示教师与教室

### 6. 数据与持久化

- 选课、旁听、个人行程自动保存（localStorage），关闭重开不丢失
- PWA 离线缓存（Service Worker + manifest）：首次联网打开后，断网也能正常使用
- 学期课程数据独立存放于 courses-data.js，换学期一键更新，已选课程中仍存在的新学期课程自动保留

### 7. 多端支持

- **网页版（H5）**：GitHub Pages 在线使用，或离线单文件双击打开
- **微信小程序版**：同一套 Taro + React 源码构建，含课表 / 今日 / 选课 / 我的 四个页面

## 二、安装与使用

### 方式一：在线版（推荐，无需安装）

1. 手机或电脑浏览器打开：<https://orangeo5o4.github.io/course-app/>
2. 手机端添加到主屏幕即可当 App 使用：
   - **Android（Chrome）**：右上角三点菜单 → 「添加到主屏幕」/「安装应用」
   - **iPhone（Safari）**：底部分享按钮 → 「添加到主屏幕」
3. 首次联网打开后自动缓存，之后断网也能正常使用

### 方式二：离线单文件版

- 打开 `选课系统2.0` 文件夹，双击 `index.html` 即可使用，完全离线、无需联网
- `选课系统1.0` 为历史版本存档，一般无需使用
- 说明：离线版为早期网页版，功能以在线版为准

### 方式三：微信小程序版（需开发者工具）

环境要求：Node.js ≥ 18

```bash
cd course-miniapp
npm install
npm run dev:weapp
```

然后用微信开发者工具导入 `course-miniapp` 目录，即可预览与真机调试。正式发布需在微信公众平台注册小程序并上传代码。

### 换学期更新课程数据

**推荐方式（不依赖网络）：**

1. 电脑上双击 `更新学期数据.bat`，按提示拖入新学期 Excel 课表
2. 生成的 `course-miniapp/dist/courses-data.js` 通过微信 / QQ 发送到手机
3. 打开 App → 「我的」→ 「导入学期数据」→ 选中该文件即可
4. 建议换学期后清空旧选课，重新选课

**备用方式（联网）：** 在 GitHub 仓库页上传新的 `courses-data.js`，手机联网打开 App 自动获取新数据。

## 三、GitHub 收藏与更新

### 收藏项目

打开仓库页面 <https://github.com/orangeo5o4/course-app>：

| 操作 | 方法 | 作用 |
|------|------|------|
| Star（收藏） | 点右上角 Star 按钮 | 收藏后可在自己 GitHub 主页的 Your stars 中随时找回 |
| Watch（关注） | 点 Watch → 选 All Activity | 项目每次更新都会收到通知；只想收重要通知可选 Custom |
| Fork（副本） | 点右上角 Fork | 把项目复制到自己账号下，可独立修改 |

### 获取最新版本

- **在线版用户**：App 带离线缓存。项目更新后，联网打开页面稍等片刻，然后完全关闭再重新打开一次，即可自动切换到新版（Service Worker 自动更新机制）
- **手动下载**：仓库页绿色 Code 按钮 → Download ZIP，解压后打开 index.html 即可离线使用
- 最新功能以在线地址 <https://orangeo5o4.github.io/course-app/> 为准

### 发布更新（项目所有者）

**网页上传（无需安装 Git，与现有部署流程一致）：**

1. 本地修改代码后构建：`cd course-miniapp && npm run build:h5`
2. 打开仓库 → Add file → Upload files
3. 将 `course-miniapp/dist` 中的全部内容拖入上传区（js / css / icons 目录结构会自动保持）
4. 填写更新说明 → Commit changes，约 1 分钟后线上自动生效

**命令行方式（可选）：**

```bash
git clone https://github.com/orangeo5o4/course-app.git
# 将 dist 中的全部内容复制进仓库目录后：
git add .
git commit -m "更新说明"
git push
```

## 四、项目结构

```
选课/
├── 选课系统1.0/             # 网页版历史存档
├── 选课系统2.0/             # 网页版离线单文件（双击 index.html 使用）

│   ├── src/pages/           #   课表、今日、选课、我的 四个页面
│   ├── src/components/      #   课程卡片、冲突弹窗、行程弹窗等
│   ├── src/data/            #   学期课程数据（courses-data.js）
│   ├── src/utils/           #   冲突检测、日期周次、图片导出等工具
│   └── dist/                #   构建产物（部署到 GitHub Pages 的内容）
├── 更新学期数据.bat           # 一键由 Excel 生成新学期数据
├── gen_courses_data.py      # 学期数据生成脚本（供 bat 调用）
├── gen_icons.py             # PWA 图标生成脚本
└── 2026年秋季学期课表.xlsx    # 本学期课程源数据
```

## 五、常见问题

**Q：打开在线地址显示 404？**
A：Pages 刚开启需要等 1-2 分钟生效；或检查仓库 Settings → Pages 中 Branch 是否为 main / (root)。

**Q：更新后手机还是旧课表？**
A：离线缓存所致。联网打开 App 稍等后完全关闭，再重新打开一次即可拿到新版。

**Q：数据会上传到服务器吗？**
A：不会。所有选课与行程数据仅保存在你自己的设备（localStorage）中，项目无任何后端。

**Q：仓库可以设为私有吗？**
A：免费账号的 GitHub Pages 仅支持公开仓库；本项目不含个人隐私数据，公开即可。
